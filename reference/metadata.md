# Metadata for `netData`

A data.frame with extended information about the 29 networks from (1),
included in `netData`

## Usage

``` r
metadata
```

## Format

A data frame

- Network:

  Name of the network

- Longitude:

  Longitude of the geographical coordinates of the network

- Latitude:

  Latitude of the geographical coordinates of the network

- Date:

  Date range or approximate date when the data was collected

- InteractionsSource:

  Method used to determine the interactions

- Reference:

  Reference of the study from where data was obtained

- ReferenceLink:

  URL of the reference
